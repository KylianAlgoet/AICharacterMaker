# AI 3D Character Maker (Tripo + OpenAI)

Dit project bevat:

- **Backend (Node + Express)**: API voor prompt enhancing, Tripo text-to-3D, en (placeholder) auto-rig endpoint.
- **Frontend (React + Vite + Three.js)**: interface met prompt form, history, en 3D viewer.

## Quickstart

```bash
git clone <repo-url>
cd ai-3d-character-maker
```

### Backend

```bash
cd backend
npm install
# maak .env file met je API keys
npm start
```

### Frontend

```bash
cd ../frontend
npm install
npm run dev
```

Open daarna de URL van Vite (standaard http://localhost:5173).
